# GEO-SCOPE — 自動更新つき公開セット

> 別 PC・別アカウントへ移行した場合は、まず **`HANDOFF.md`**（現状・確定仕様・TODO・セットアップ手順）を読んでください。

`site/` をそのまま静的ホスティングすれば動きます。GitHub Actions が2時間ごとに `site/news.json` を更新し、GitHub Pages に配信します。Claudeのアカウントやスケジュール機能には依存しません。

## セットアップ（10分）
1. このフォルダを新しいGitHubリポジトリにpush（公開/非公開どちらでも可。非公開でもPagesは使えます）
2. Settings → Secrets and variables → Actions → **New repository secret**
   - `ANTHROPIC_API_KEY` : Claude Console で発行したAPIキー
   - （任意）Variables に `GEOSCOPE_MODEL` を置くとモデルを差し替えられます（既定 `claude-sonnet-5-5`）
3. Settings → Pages → Source を **GitHub Actions** に
4. Actions タブ → "Update GEO-SCOPE news feed" → **Run workflow** で初回実行
5. 公開URL `https://<user>.github.io/<repo>/` を開く。配信用は末尾に `#live`

## 仕組み
- `scripts/update_news.mjs` は 2 段階で動きます（**SOURCE=feeds、既定**）
  1. **記事集め（無料）**：`scripts/feeds.json` に並べた公式 RSS（NHK・BBC・Al Jazeera・Guardian・NYT・NPR・DW・France24・国連ニュース・ReliefWeb）と GDELT（世界の報道の無料索引）から直近 8 時間の記事を集め、URL と見出しで重複を除き、国名の別名辞書で「推定国」を付けて最大 160 件の候補に絞ります。前回までに Claude に渡した記事は `.cache/feed_seen.json` に覚えておき、二度と送りません（＝二重に課金されない）
  2. **選別・要約・翻訳（Claude、検索ツールなし）**：候補の見出しと短い説明だけを渡し、重要な出来事を選んで日本語・英語で要約、国・重要度・アラート種別・関連国を付けさせます。Claude には根拠にした**候補番号**だけを書かせ、出典 URL はスクリプトが候補の実 URL から付けます（存在しない URL は入りません。根拠番号の無い項目は捨てます）
  - 以前の「Claude の web 検索で集める」方式も `SOURCE=search` で使えます（約 10 倍のコスト。フィードがすべて取れないときの非常用）
  - その後、検証→重複除去→7日より古い項目を削除→各国最大6件に整形して `news.json` を書き換えます
- **収集元の追加・削除**は `scripts/feeds.json` を編集するだけ（`name` / `url` / `lang` / `tag`＝既定の国キー / `weight`＝優先度）。取れないフィードは飛ばして続行します。国名の別名（「キーウ」→ Ukraine など）も同じファイルの `country_aliases` で足せます
- ページは5分おきに `news.json` を取得し、リロードなしで差分を取り込みます（新着時はLINK表示が光り通知音）
- 各項目には `alert_type`（emerg/nuke/cyber/quake/break）と `rel`（関連国キー、最大3）を Claude が付けます。ページの全画面アラート判定と関連国ピンはこれを優先し、無いときだけキーワード辞書で補います
- **初期化モード**: Actions の「Run workflow」で `init` にチェックを入れて実行すると、日付付きニュースが1件もない国に対して1件ずつ概況を作ります（1回40か国。194か国なら3回）。新しく追加した国を初日から地図の巡回に入れたいときに使います。ローカルなら `INIT=1 node scripts/update_news.mjs`
- APIが失敗した回は `updated` だけ更新して配信を止めません

## コスト目安（SOURCE=feeds、Sonnet 5.5、1ドル=158円で試算）
- 世界ニュース：1 回あたり入力 2〜3 万トークン・出力 6〜9 千トークン ≒ 0.1〜0.15 ドル。**4 時間おき（1日6回）で月 約 20〜27 ドル ≒ 3〜4 千円**
- 地域枠（日本＋米国）：1 日 2 回 × 2 呼び出し ≒ 月 約 5 ドル ≒ 800 円（日本だけなら約半分）
- 合計 **月 4〜5 千円前後**。旧方式（web 検索）だと同じ頻度で月 2〜3 万円
- RSS・GDELT・地震・災害・マーケット・音声合成（VOICEVOX / Piper）・GitHub Actions（公開リポジトリ）は無料
- 各スクリプトは実行のたびに `usage: in … / out … ≈ $…` を表示するので、Actions のログで実費を確認できます（単価は `PRICE_IN` / `PRICE_OUT` 環境変数で変更）
- さらに下げるなら：`MODEL=claude-haiku-5-5`（Variables の `GEOSCOPE_MODEL`）、`MAX_CANDIDATES=100`、地域枠を日本だけ（Variables の `GEOSCOPE_REGIONS=japan`）
- 頻度は `update-news.yml` の cron（既定 4 時間おき）。地域枠は同じジョブの中で UTC 8時・20時台（JST 17時・5時台）の 2 回だけ動きます。手元の `local_loop.mjs` も既定 4 時間おき・地域枠 12 時間おき

## 配信用レイアウトと環境BGM
- ヘッダーの **LIVE** ボタンで配信用レイアウトに切り替え（URLに `#live` が付く＝OBSのブラウザソースにそのまま使える）。右パネルと国リストを隠して地図を全面に、文字と光点を大きく、右下に時計・フィード状態・コマンド案内・音声クレジットを表示。もう一度押すか Esc で通常表示に戻ります
- **BGM** ボタンで環境BGM（その場で生成。音源ファイルも著作権もなし）。内容は「倍音浴／ディープヒーリング」系：432Hz 系のドローン（108Hz の倍音1〜6をわずかにずらした対で重ね、ゆっくり唸る）、左右 432/440Hz のバイノーラル（8Hz α波、ヘッドホン向け）、1分に6回の呼吸のような揺らぎ、22〜45秒おきのシンギングボウル（136.1／174／285／396／417／528Hz、12秒の余韻）、ごく薄い空気のノイズ。読み上げ中と全画面アラート中は自動で音量を下げます。音量は `BGM` 内の各 `gain` で調整
- **SND・VOICE・BGM は独立**しています。SND が OFF でも VOICE だけ ON にすれば読み上げ（とその前後のスケルチ音）が出ます。SND は効果音（レーダー・タイプ音・通知・無線ノイズ）だけを司ります

## 配信の安定運用
- **ブラウザのタブを裏に回すと止まる件**: Chrome/Edge は非表示タブのタイマーを間引きます（5分で1分に1回まで）。音が鳴っているタブは対象外なので、SND か BGM を ON にしておけば裏でも動き続けます。確実なのは OBS の「ブラウザソース」で読み込む（常に前面扱い）か、別ウィンドウで最小化せずに置いておくことです
- 配信モード（`#live`）では6時間ごとに自動リロードします（アラートやコールアウト表示中は終わるまで待ちます）。ブラウザソースのメモリを平らに保つためで、OBS側の設定は不要です
- 自動巡回は1か国10秒。読み上げが10秒で終わらないときは5秒ずつ延長（それでも終わらなければさらに5秒）。アラートやリスナーコマンドの表示中も同じ5秒刻みで待ちます
- ティッカーは直近24時間の見出しを流し、8件未満の静かな日は3日分に広げます


### 負荷について
- v74 で 50 分のソークテスト（#live・アラート試験・地域枠・国紹介を含む）を実施：JS ヒープ 2.6〜3.6 MB・DOM 要素数・タイマー数とも横ばい、ページエラー 0。メモリリークはありません
- CPU の主因は地図上の光点の脈動アニメーション（SVG なので描画スレッドで処理される）でした。v74 からは **ニュースのある国だけが脈動**し、静かな国は小さな固定の点になります（描画負荷 約 3 割減）。それでも重い PC では `#live,lite` で走査線などを切れます

### 長時間稼働の確認（ソークテスト）
`scripts/soak_test.cjs` は、ビルド済みサイトをヘッドレス Chrome で `#live`（アラート試験モード＋地域枠を12分おきに起動）のまま回し、1 分ごとにヒープ・DOM 要素数・生きているタイマー数・Web Audio ノード生成数・ページエラーを CSV に記録します（`npm i playwright && npx playwright install chromium` が必要、`node scripts/soak_test.cjs 60 soak.csv`）。ページを大きく変えたあとに 1 時間回して、ヒープと DOM が横ばいであることを確認してください。

### 画面上の自己診断（v74〜）
OBS の映像だけ見ていても異常に気づけるよう、ヘッダーの `LINK:` の右に黄色いバッジが出ます。
- **フィード停滞**：`news.json` の更新時刻が 3 時間以上前（`LINK:` にも `STALE 5h` のように経過時間）。更新ジョブ（Actions / `local_loop.mjs`）が止まっていないか確認
- **フィード不通**：`news.json` の取得に 3 回連続で失敗（`LINK: NO FEED`）。サーバーや GitHub Pages 側の問題
- **音声パック無し**：音声索引（`voice/index.json`）が読めず、すべてブラウザ音声で代読している
- **音声 代読中**：索引はあるが直近 20 件のうち過半数がクリップ無し（ニュースは更新されたのに音声生成が追いついていない）。右下の VOICE 行にも `ブラウザ代読 7/20件` と出ます。VOICEVOX を起動して `node scripts/synth_voice.mjs` を走らせれば解消
正常時はバッジは出ません。
## 表示期間と国紹介（ヘッダーの設定）
- **24H / 3D / 7D**：地図のコールアウト・自動巡回・ティッカー・光点の色に載せるニュースの期間。ブラウザに記憶され、URL でも指定できます（例 `#live,days=1`）。右パネルの「情勢」タブはどの設定でも保持分（最大7日）を全部見せます
- **PROFILE OFF / 3 / ALL**：ニュースのある国を1巡し終えるたびに「国紹介」を挟みます。首都・人口・政体・渡航レベル・日本との関係をコールアウトに出して読み上げ（1か国12秒、読み上げが長ければ5秒ずつ延長）、右パネルは自動で「基本情報」タブに切り替わります。`3` は先頭3か国、`ALL` はその巡回の全か国。URL では `profile=all` など
- 国紹介の音声は `scripts/synth_profile.mjs` が国ごとに1回だけ生成します（日本語 VOICEVOX＋英語 Piper、`voice/profile_<ISO>_<lang>.ogg`、`index_profile.json`）。Actions の更新ジョブに組み込み済みで、基本情報の文面が変わった国だけ作り直します。手元: `node scripts/synth_profile.mjs`（`LANGS=ja` で日本語のみ、`ONLY=JPN,USA` で一部だけ）
- **配信はどちらが良いか**：24時間配信なら **3D を推奨**します。24H だと静かな日に10〜20件しか無く、5分弱で同じニュースが戻ってきて単調になります。3D なら60〜80件で巡回が15分前後になり、相対時刻（「2日前」）が出るので古さも伝わります。「今日だけ知りたい」人向けには、ティッカーが常に直近24時間を先に流す設計になっているので、画面上部を見れば当日分が追えます。速報性を前面に出す配信枠（朝のまとめ等）だけ 24H にする、という使い分けが現実的です

## ヘッダーの設定 UI（v71〜）
- 1段目は状態表示（LIVE FEED / MODE / NEXT / 時計）、2段目に主要トグル **SND・VOICE・BGM・EN・LIVE** と **⚙ SET** だけを置きました。SET を押すと小さなパネルが開き、表示期間（24H/3D/7D）、国紹介（PROFILE）、地域経済枠（REGIONS）、毎正時のまとめ、英語音声の方式、ポリシーへのリンク、バージョン表示をまとめています。設定はブラウザに記憶されます
- スマホ幅ではトグルが2段目に折り返し、SET パネルは画面下からのシートになります。LIVE 中は2段目を自動で隠します（マウスを上端に当てると出ます）

## 地域経済の時間帯（都道府県 / 米国州）
- 毎時 **:20 に日本の都道府県経済**（日経地方経済面のような粒度：工場新設・雇用・観光・地銀・再開発など）、**:50 に米国の州別経済**（州の雇用統計・投資・州法の経済影響など）の枠が入ります。地図は日本列島／米本土にズームし、該当都道府県・州にピンを打って1件10秒ずつ巡回し、最長6分で世界巡回に戻ります（件数が少なければその分早く戻ります）。読み上げ・コールアウト・出典リンクは通常ニュースと同じです
- データは `site/regions.json`（`scripts/update_regions.mjs` が NHK 経済・Nikkei Asia・NPR / NYT Business などの RSS と GDELT から都道府県名・州名・主要都市名を含む記事を集め、Claude が検索なしで選別・要約。7日保持、1地域3件まで）。地方紙や自治体の RSS を `feeds.json` の `japan` に足すと都道府県のカバーが広がります。Actions の更新ジョブに組み込み済みです。手元では `node scripts/update_regions.mjs`（`REGIONS=japan` で日本のみ、`DRY_RUN=1` で書き込まずに確認）。**全 47 都道府県・全州を最初に埋めたい**ときは `INIT=1 node scripts/update_regions.mjs`（Actions では手動実行の `init` にチェック）。ニュースの無い地域には直近 1 週間の経済トピック（主要産業・観光・求人・自治体施策）を 1 件ずつ入れます
- 音声は `synth_voice.mjs` / `synth_voice_en.mjs` が `regions.json` の項目も一緒に生成します（読み上げの冒頭は「北海道。」「Hokkaido, Japan.」「Texas.」）
- 設定 SET → **REGIONS** で `毎時 / なし` を切り替え、URL では `regions=hourly|off`。コンソールから `GEOSCOPE.region('japan')` で今すぐ開始、`GEOSCOPE.regionStop()` で中断
- 同梱の `regions.json` は表示確認用のサンプル（見出しに【サンプル】）で、最初の更新で実データに置き換わります

## 音量の均一化（ラウドネス正規化）
- 音声スクリプト（`synth_voice.mjs` / `synth_voice_en.mjs` / `synth_profile.mjs`）は生成時にクリップの音量を揃えます。ffmpeg がある環境では EBU R128 の loudnorm（**-16 LUFS / TP -1.5 dB**）、無い環境（WAV 保存）では純 JS の RMS 正規化（-17 dBFS、ピーク -1 dBFS 以内）で、VOICEVOX と Piper の声量差・項目ごとのばらつきを吸収します
- 正規化前に作った既存クリップは `node scripts/normalize_voice.mjs` で一括処理できます（WAV は ffmpeg 不要、OGG は ffmpeg がある場合のみ。2 回走らせても変化しません）
- 目標値は `LUFS=-14` / `RMS_DB=-15` のように環境変数で変更できます（YouTube の基準は -14 LUFS ですが、BGM との兼ね合いで少し低めの -16 を既定にしています）

## 番組進行（ON AIR 表示・毎正時のまとめ・マーケット）
- **ON AIR 行**（LIVE レイアウトの右下）：いま流している枠（WORLD WATCH / JP REGION / US REGION / HOURLY DIGEST / ALERT）と、次の枠の開始時刻・残り分数を常時表示します。視聴者が「次に何が来るか」を見られる放送局風の進行表示です
- **毎正時のまとめ（TOP OF THE HOUR）**：毎時 00 分に直近 1 時間の主な見出しを最大 6 件 × 10 秒（約 1 分）流します。静かな時間帯は 3 時間まで広げ、それでも足りなければ最新 6 件。重要度（alert → warn → info）順、1 か国 1 件。SET → **毎正時のまとめ** で `なし` に、URL では `digest=off`。コンソール `GEOSCOPE.digest()` で即時開始
- 1 時間の流れ：`:00` まとめ（1 分）→ 世界巡回 → `:20` 都道府県経済（最長 6 分）→ 世界巡回 → `:50` 米国州別経済（最長 6 分）→ `:00`
- **マーケット表示**：ヘッダー右側に日経平均・S&P500・ダウ・ドル円・ユーロ円・BTC・金を 3 銘柄ずつ 8 秒で回して表示します。データは `site/markets.json`（`scripts/update_markets.mjs` が Stooq の CSV から取得、API キー・費用なし。FX と BTC は ECB / Coinbase にフォールバック）。`.github/workflows/update-markets.yml` が平日 30 分おき・週末 3 時間おきに更新して Pages を再デプロイします（不要なら このファイルを削除）。手元では `local_loop.mjs` が 30 分おき（`MARKETS_MIN=0` で無効）。36 時間以上古いデータは表示しません。同梱の `markets.json` はサンプルです
- 注意：Stooq の指数は終値ベース（遅延あり）です。リアルタイム相場ではなく「今日の地合い」を示す目的の表示なので、画面上も騰落率のみで時刻は出していません

## 新着ニュースと読み上げの関係
- **本番（Actions）**: 2時間ごとの更新ジョブが「ニュース取得 → 日本語音声 → 英語音声 → 公開」を一気に行うので、新着ニュースは公開時点で音声付きです。ページは5分ごとに `news.json` と音声索引を読み直すため、配信を止めずに新着が巡回に入り、読み上げられます
- **音声がまだ無い項目**（索引より新しいニュース、概況など）は無音にせず、ブラウザ内蔵の音声で代読します。次の生成が走ればクリップに切り替わります
- **手元で回す場合**: `node scripts/local_loop.mjs` を起動しておくと、一定間隔（既定120分）で「ニュース更新（`ANTHROPIC_API_KEY` があれば）→ 日本語音声 → 英語音声」を自動で繰り返します。`serve_local.mjs` と並行して動かせば、PC1台で Actions と同じ運転になります（`INTERVAL_MIN=60` などで間隔変更、`SKIP_NEWS=1` で音声だけ）

## 自前サーバー・OBSで使う場合
- `site/index.html` と `site/news.json` を同じディレクトリに置くだけ
- OBS: ブラウザソースに公開URL + `#live`、幅1920 高さ1080、「表示されていないときにソースをシャットダウン」はオフ
- 音を配信に乗せるときは、ページ内の `SND` を一度クリックしてON（OBSの「操作」ボタンから）

## データの手直し
- `site/news.json` を直接編集してpushすれば次回の取得で反映されます（Actionsはそこに追記します）
- 国の追加・基本情報の修正は `site/index.html` 内の `const DATA = {...}` を編集（`scripts/data_all.json` が元データ）
- 収録国は国連加盟193か国＋台湾（194）。地図の陸地データ（Natural Earth 110m）に形がない小島嶼国・都市国家（シンガポール、マルタ、モルディブ、バーレーン、カリブ・太平洋の島嶼国など）は `pos` の光点のみで表示され、陸地のハイライトは出ません。日付変更線付近（ツバル・フィジー・トンガ等）は地図を左右に折り返して表示します
- 初期収録の104か国は詳しいプロフィール、残り90か国は簡易プロフィール（GDP・輸出品・邦人数などは未収録）。`scripts/data_all.json` に追記すれば画面にも反映されます

## リスナーコメント連携（YouTube Live）
ページは3つの入口でコマンド `!国名`（例: `!日本` `!イラン` `!usa`）を受け付けます。
1. 同じディレクトリの `commands.json`（3秒おきに読む）
2. `index.html?cmd=ws://localhost:8787` で開いたときの WebSocket
3. `window.postMessage({type:'geo-cmd', text:'!日本', user:'name'})` / コンソールから `GEOSCOPE.cmd('!日本','name')`

`scripts/chat_relay.mjs` を配信PCで動かすと、YouTube Data API からライブチャットを取得して 1 と 2 に流します。
```
npm i ws   # 任意（WebSocketを使う場合）
YT_API_KEY=xxxx VIDEO_ID=yyyy node scripts/chat_relay.mjs
```
ページ側の制御: 同一ユーザーは60秒に1回、キューは最大5件、リクエスト表示中は20秒間自動巡回を止め、枠に `REQ: ユーザー名` を表示します。

**サイト上にコメント欄はありません。** 静的サイト（GitHub Pages）なので書き込みを受ける仕組みが無く、コメントは YouTube Live のチャットが担います。`chat_relay.mjs` はコマンド以外の発言も `chat.json` に書き出し（直近12件・ユーザー名と本文のみ・URLは除去、`CHAT_KEEP=20` で件数変更）、ページは LIVE レイアウトのとき **左下に直近のコメントを流します**（5秒おきに読み直し、同じ発言は1回だけ）。手動で足すなら `GEOSCOPE.chat('name','text')`（直近6件を表示）。配信画面に出したくない場合は `#live,chat=off`。

## ニュース読み上げ（VOICEVOX）
- Actions の `update` ジョブで VOICEVOX エンジン（Docker, CPU版）を起動し、`scripts/synth_voice.mjs` が直近3日分のニュースを音声化して `site/voice/*.ogg` と `site/voice/index.json` を生成します
- 上部の **VOICE** ボタンで読み上げ ON/OFF（設定はブラウザに記憶）。`voice/index.json` があれば VOICEVOX の音声を無線加工して再生し、無いとき（プレビュー中・Actions 初回実行前）は **ブラウザ内蔵の音声合成**で代読します（Windows は Microsoft Nanami 等、Mac は Kyoko 等。こちらは無線加工は掛からず、前後のスケルチ音のみ）。配信モードの右下に、どちらのエンジンで読んでいるかが表示されます
- **英語モード（EN）は Piper TTS の英語クリップ**で読み上げます（`scripts/synth_voice_en.mjs` → `site/voice/en_*.ogg` + `index_en.json`）。Piper はオープンソース・オフラインの音声合成で、Actions では自動でインストールと音声モデルの取得（キャッシュ）を行います。日本語と同じ鍵で紐づき、ページ側で同じ無線加工を通すので雰囲気が揃います。英語クリップが無いときはブラウザ内蔵の英語音声で代読（無線加工なし）
- 英語はブラウザ内蔵の声（Edge/Chrome の Microsoft Aria などは非常に自然）を使い続けることもできます: コンソールで `GEOSCOPE.voiceEn('browser')`（戻すときは `'piper'`）。ただしブラウザ音声は Web Audio に通せないため、無線加工は「下に敷くノイズとクラックル＋前後のスケルチ音」まで。声そのものの歪み・帯域制限が掛かるのは Piper クリップだけです
- 英語の声は Variables `GEOSCOPE_PIPER_VOICE` で変更（既定 `en_US-amy-medium` = 明瞭な女性）。候補: `en_US-lessac-medium`（落ち着いた女性アナウンサー調）、`en_US-kristin-medium`、`en_GB-alba-medium`（英国女性）、`en_US-joe-medium`（男性）、`en_US-ryan-high`（男性）。話速は `LENGTH_SCALE`（既定 0.8、小さいほど速い）。読み間違いは `scripts/readings_en.json`
- 手元で英語クリップを作る: `pip install piper-tts` → `python -m piper.download_voices en_US-amy-medium --data-dir .piper` → `node scripts/synth_voice_en.mjs`。声の聞き比べは `node scripts/voice_sample_en.mjs`（候補モデルを取得して同じ文を合成、`voice_samples_en/index.html` で無線加工つき再生）
- ONにすると地図上のニュース表示に合わせて読み上げます。音声は帯域制限・軽い歪み・スケルチ音・微かなノイズを通した「無線越しの管制官」風に加工され、読み上げ中は自動巡回が待機します
- 話者は Variables `GEOSCOPE_SPEAKER` で変更（既定 30 = No.7 アナウンス。29=ノーマル、31=読み聞かせ）。既定の話し方は速め・抑揚強め・間を短く（`SPEED` 1.25 / `PITCH` 0.02 / `INTONATION` 1.35 / `VOLUME` 1.1 / `PAUSE` 0.7）で、緊張感のあるオペレーター調。無線加工は 400–2600Hz・歪み最大・ノイズ多め・前後に控えめ（0.4）のスケルチ音（2026-11-05 聞き比べで決定）
- 読み間違いは `scripts/readings.json` に表記→読みを追加
- クレジット表記はページ右下（配信モード）に自動表示されます。使用キャラクターの利用規約（VOICEVOX公式サイト）を確認してください
- **配信するだけならPCへのインストールは不要**（Actions 内の Docker で完結）。声を選びたいときだけ、VOICEVOX アプリ（無料、https://voicevox.hiroshiba.jp/ ）を入れます
- **声の聞き比べ**: VOICEVOX アプリを起動した状態で `node scripts/voice_sample.mjs` → `voice_samples/index.html` を開くと、管制官向きの女性候補（波音リツ・冥鳴ひまり・ナースロボ＿タイプＴ・九州そら・四国めたん など）で同じ文を合成し、素の音声と「無線で再生」ボタン（配信ページと同じ加工をブラウザ内でかける。ffmpeg 不要。歪み・ノイズ・帯域はスライダーで調整可）を並べて聞き比べられます。`SPEAKERS=9,14,47` でIDを直接指定（男性声も試すなら `SPEAKERS=13,11`）、`TEXT="..."` で文を変更。気に入ったIDを `GEOSCOPE_SPEAKER` に設定
- **手元で VOICEVOX 音声を作って聞く**（Actions を回す前の確認）: VOICEVOX アプリを起動 → `node scripts/synth_voice.mjs`（直近3日分のニュースを `site/voice/` に生成。ffmpeg があれば ogg、無ければ WAV）→ `node scripts/serve_local.mjs` → ブラウザで http://localhost:8080/ を開き VOICE を ON。これで本番と同じ No.7＋無線加工の読み上げになります。ニュースが更新されたら `synth_voice.mjs` を再実行（差分だけ作ります）
- ffmpeg を入れると音声が約1/10のサイズ（ogg）になります: Windows `winget install ffmpeg` / Mac `brew install ffmpeg`

## 災害レイヤー
- `scripts/fetch_disasters.mjs`（地震用ワークフローと同じ15分ごと）が GDACS（台風・洪水・火山・山火事・干ばつ、警戒レベル付き）、NOAA NHC（大西洋・東太平洋のハリケーン）、気象庁 台風情報（ベストエフォート）、NWS（米国の竜巻警報）を統合して `site/disasters.json` を生成
- 自前ホスティングではページがGDACSとNWSに直接アクセスを試み、だめなら `disasters.json` を読みます。赤レベルの新規の熱帯低気圧・竜巻警報・火山は画面上部に DISASTER ALERT を出して現地へズーム

## 出典記事へのリンク
- 出典URLがあるニュースは、地図上のコールアウト全体・右パネルの見出し（↗）・上部ティッカーの各項目がクリックで元記事を新しいタブに開きます。URLが無い項目（概況など）はクリックできません

## 地図上のコールアウト演出
- ピン → 斜線 → 横線とリーダー線が伸び（0.5秒）、線が到達した点から枠が描かれ（縦辺 → 上下辺 → 反対の縦辺、約0.6秒）、枠が閉じてから背景と本文が現れてタイプ開始します
- 見出し・本文に他国名（日本語・英語・首都名・指導者名など `REL_EXTRA` の辞書）が含まれていれば、約2秒後にその国へ破線を引いて「関連」ピンを打ちます（最大3か国）。画面外なら両方が収まるように一度ズームアウトします。フィード側で `item.rel=["Russia","Ukraine"]` を付ければ辞書より優先されます

## 無線ノイズと画面の乱れ
- 音ON時、14〜40秒おきにランダムで無線の「ザザッ」（広帯域ノイズ＋歪み＋速いゲート）と聞き取れない交信が入ります。0.6秒より長い交信のときは同時に地図が乱れます（SVGフィルタによる横方向の歪みとティア、RGBの色ずれ、黒い欠落行、走査線、スペックルノイズ、まれに一瞬のブラックアウト、HUDに「SIGNAL WEAK」）
- 手動: `GEOSCOPE.glitch(ms, 強さ0〜1)`（例 `GEOSCOPE.glitch(800,1)`）。`prefers-reduced-motion` の環境では出ません

## 直近24時間のアラート一覧（右上）
- 全画面アラートが出た項目は、その後24時間、地図右上に点滅なしの小さな一覧として残ります（最大4件、新しい順）。途中から見始めた視聴者向けです。600px未満の画面では非表示

## 全画面アラート（重要ニュース）
- 地図中央に二重線の点滅枠で「STATE OF EMERGENCY／SEISMIC ALERT／NUCLEAR / BIO ALERT／CYBER ALERT／BREAKING NEWS」（Helvetica Bold系・縦長の中抜き文字）＋英語国名だけを表示。対象は**出来事から24時間以内**の項目だけで、1件につき1回（ページ読み込み直後は直近3件まで）。8秒表示したあと該当国へズームします。赤（緊急事態）はサイレン音、紫・青はアラート音3連、黄・白はアラート音＋チャイム
- 分類（見出し・本文のキーワード → 色）: 緊急事態宣言・非常事態宣言・戒厳令 → **赤**／地震・津波（ニュース項目と地震レイヤーの速報） → **黄**／核弾頭・核ミサイル・ICBM・弾道ミサイル発射・ウイルス・感染症・パンデミック → **紫**／サイバー攻撃・情報漏洩・ランサムウェア・不正アクセス → **青**／上記以外の `lv:"alert"` → **白**
- 8秒表示のあと該当国へズームし、**そのアラートになったニュース**をコールアウトで表示します（巡回順の別のニュースではなく）
- テスト巡回: URL末尾に `#alerttest`（配信モードなら `#live,alerttest`）を付けると、4秒後から5種類を20秒おきに順番に表示し続けます（日本→米国→ウクライナ→台湾→ドイツ）。コンソールなら `GEOSCOPE.alertDemo()`（引数で間隔ms）
- キーワードは `src/page.html` の `const ALERT` 内 `RX` で調整。表示テストはブラウザのコンソールで `GEOSCOPE.alertTest('emerg'|'quake'|'nuke'|'cyber'|'break')`

## 英語表示
- `site/data_en.json` が英語オーバーレイ（基本情報・渡航注記・日本との関係・世界一・電圧・知識・伝承・ニュース見出しと本文）。ページは起動時と10分おきに読み込み、EN切替時に差し替えます。未訳の項目は日本語のまま表示
